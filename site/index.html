FinOps: lo que cuesta producir estos datos

Cada dbt build deja una fila en ops/pipeline_runs. El costo es la duración medida × el precio de lista de una Lambda arm64 de 3 GB. La duración se midió en un runner de GitHub Actions, no en Lambda, así que es una estimación de orden de magnitud.
